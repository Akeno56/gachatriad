# Draft — current implementation

The user replaced the former Arena run plan with single-duel Draft. The seven-win/three-loss run remains superseded; v0.10 restores a three-booster, fifteen-card selection for each individual Draft duel.

The [official FFXIV guide](https://na.finalfantasyxiv.com/lodestone/playguide/contentsguide/goldsaucer/tripletriad/) describes selecting five cards from a random offering without using owned cards. Our v0.10 design automatically opens **three five-card boosters** per player, then offers the resulting **15 distinct characters**. Each pack rolls three random cards, one 3★+ and one 4★+. Holo is 5% per card. These pack mechanics and pool size are Gacha Triad choices, not claims about FFXIV. See [exact odds and persistence](BOOSTER_PACKS.md).

The ceremony needs no clicks, preloads artwork, reveals one card at a time and finishes each pack before opening the next. Reveal progress persists, so reload resumes without rerolling. The 15 revealed offers sort by total stats then rarity, with an alternate rarity-first order. Desktop uses two compact rows, while mobile scrolls. Choose five distinct cards within the normal rarity limit before the three-minute draft deadline, which includes opening time. Players see only their own pool. Locking is final. When both hands lock, a single Three Open + Same/Plus/Combo match begins, with no card trade. At timeout the server fills unlocked hands with legal random choices. Draft uses no permanent boosters, has no entry fee and never adds cards to inventory. Normal completed-duel Prism rewards apply. Leaving during the draft forfeits the rated duel, discouraging pool rerolls.

Draft requires a registered account, uses its own lobby/queue category and independent persistent `draft_rating`, and can be tested against labeled local bots. The initial rating is 1000 and the per-duel Elo K-factor is 32. Constructed rating is unaffected. Draws score one half. Ratings and results commit in the same transaction. A new match creates a new pool.
