# Player-selected roadmap

## Current release: 0.1.4

- Daily Triad puzzle, reward and daily leaderboard.
- Shared Draft alongside the existing Draft, both with independent ranked Elo leaderboards.
- Ordinary Ranked without collection loss; Trade One remains optional in custom games.

## Near future — planned, not included in 0.1.4

- Flexible weekly objectives.
- A player journey journal introducing the game's activities.
- Named deck loadouts.
- A deck strength and weakness view.
- Saved match replays.
- Portrait frames.
- A card-tavern home page.
- More configurable public profiles.
- More distinctive bot personalities.
- A dedicated deckbuilding workspace.
- A complete shared control system.
- Stronger seasonal identity.
- A more satisfying results screen.

Other proposed improvements remain possible, but are not priorities yet. Preserve the FF/pixel style and design primarily for mouse/touch interaction.
